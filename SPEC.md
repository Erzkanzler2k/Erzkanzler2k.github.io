# Erzkanzler — личное портфолио: спецификация

## Цель
Личный некоммерческий сайт инженера-разработчика на домене `erzkanzler.is-a.dev`:
показать проекты, стек и подход, дать канал связи через GitHub.

## Аудитория
Разработчики, мейнтейнеры open-source и все, кто приходит по ссылке из профиля.

## Критерии приёмки
1. Русскоязычная одностраничная версия, тёмная премиум-эстетика, адаптив 320–2560px.
2. Секции: hero, «сейчас», о себе, 6 работ, стек, подход, контакты, футер.
3. Никаких фреймворков и JS-зависимостей, кроме Google Fonts.
4. SEO: title, description, canonical, Open Graph (включая картинку 1200×630),
   JSON-LD `Person`, robots.txt, sitemap.xml.
5. Доступность: семантические лендмарки, skip-link, focus-visible, aria,
   prefers-reduced-motion, клавиатурное меню.
6. Публичный URL `https://erzkanzler.is-a.dev/` отвечает 200 по HTTPS,
   контент совпадает с репозиторием.
7. `node tests/check.mjs` — зелёный.

## Не-цели
- Коммерческие услуги, прайсы, приём заявок: сайт личный, некоммерческий
  (требование is-a.dev).
- CMS, бэкенд, аналитика, cookie-баннеры.
- Мультиязычность (только ru).

## Деплой
Репозиторий `Erzkanzler2k/Erzkanzler2k.github.io`, ветка `main`,
GitHub Pages из корня, CNAME `erzkanzler.is-a.dev` → `erzkanzler2k.github.io`.

Студия вынесена в отдельный репозиторий `Erzkanzler2k/studio` и живёт на
`studio.erzkanzler.is-a.dev`.

## Правки контента
Имя, оффер, работы, стек и контакты — в `index.html`. Сборка не нужна.
